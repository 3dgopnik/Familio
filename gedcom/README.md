## Известные проблемы в GEDCOM

1. @I7@ (Евдокия Красовська) — SEX указан M (мужской), должен быть F
2. @I121@ и @I122@ — два Николая Крупенина с похожими данными, возможный дубликат
3. @F37@ — семья с двумя мужьями (ошибка структуры)
4. Ряд лиц имеет только "?" как имя — не идентифицированы
5. Некоторые записи без дат и мест — только имя
